# Pipeline Skills for AI Agents

Industrial pipeline transient simulation skills for AI coding agents (OpenClaw, Claude Code, Codex).

## Skills

- `skills/pipeline-basics.md` — Core physics & unit system
- `skills/water-hammer.md` — Water hammer analysis & configuration
- `skills/solver-selection.md` — Solver selection guide & templates

- numpy, matplotlib, plotly
